# Panduan Rekaman Demo — JanatulAulia Studio

Gunakan akun admin dan data dummy. Jangan tampilkan password, data pelanggan sungguhan, atau API key.

1. Perkenalkan masalah yang diselesaikan dan tujuan website JanatulAulia Studio.
2. Tampilkan landing page dan bagian layanan.
3. Tampilkan portofolio dan filter kategori.
4. Kirim satu Project Brief menggunakan data dummy.
5. Login ke Dashboard Admin.
6. Jelaskan ringkasan layanan, portofolio, dan Project Brief.
7. Tambahkan layanan baru dengan status Draft; tunjukkan bahwa layanan belum tampil pada website.
8. Ubah status menjadi Published; tunjukkan layanan tampil pada website publik.
9. Tambahkan portofolio dengan gambar yang disetujui untuk digunakan; tunjukkan pada halaman Portofolio setelah dipublikasikan.
10. Buka Project Brief yang baru dikirim dan ubah statusnya.
11. Logout, lalu tunjukkan bahwa halaman admin meminta login.
12. Pada demo final, tambahkan integrasi AI, unit testing, dan GitHub Actions setelah fitur-fitur tersebut benar-benar selesai.
